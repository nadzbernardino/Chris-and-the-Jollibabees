# Woodland Preparation Quest (Chris & Babitee)

A mobile-first, QR-playable, Mario-style woodland mini-game built with **Phaser 3 + Vite + TypeScript**.

Chris isn’t saving Babitee — he’s preparing for her arrival and picking her up when he’s ready.
Six Jollibabees follow him and comment like chaotic little babies.

## Quick Start
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Core Flow

Intro → World Map → Levels 1–6 → Final Pickup → Ending
Failure (Hearts/Timer) → Game Over → Restart

## Controls

Mobile-first: tap interactions + on-screen buttons.
Desktop: click/tap prompts; minimal keyboard support.
