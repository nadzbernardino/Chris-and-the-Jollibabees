# Beehive Game – Generation Prompts (UI + Props)

Use these as **copy/paste prompts** in your image generator.  
Key rules (include in every prompt):
- **Pixel art**, retro 16-bit/8-bit vibe, cozy cottage / warm wood interior
- **Soft shadows**, subtle highlights, slightly chunky pixels
- **Transparent background (alpha)**, no checkerboard background drawn into the image
- **No text** on the object (text is added in-game)
- Centered object, clean silhouette, readable at small size

---

**STYLE ANCHOR:** “cozy pixel-art prop matching a warm, wood-and-cream cottage interior, clean outlines, soft shadow, subtle dithering, 3/2 palette harmony, game-ready UI asset, transparent background”
