# Beehive Game – Asset Template Folder

This zip is a **clean folder structure + standardized backgrounds** so you can drop in:
- your existing **characters** (Dadibee/Mamibee/Chris)  
- your **Jollibabees**  
- the new **props / UI / popups** you generate next

## What’s inside
- `assets/backgrounds/original/` — your original room BGs (mixed sizes)
- `assets/backgrounds/standard_1536x1024/` — resized/cropped to **1536×1024** (3:2)
- `assets/props/` — (empty) drop clickable props here
- `assets/ui/` — (empty) drop HUD/buttons/speech bubbles here
- `assets/popups/` — (empty) drop popup frames here
- `assets/characters/` — (empty) drop Dadibee/Mamibee/Chris here
- `assets/jollibabees/` — (empty) drop Jollibabees here
- `docs/asset_size_guide.md` — sizing recommendations
- `docs/prompts_ui_props.md` — copy/paste prompts for generating cohesive UI + props

## Quick standard
- **Backgrounds:** 1536×1024
- **Dadibee/Mamibee:** ~32×96 in-game
- **Jollibabees:** ~48×64 in-game
- **Props:** 32–64 px in-game
